# 交付追踪

状态含义：已实现、已验证、未实现、待确认。

| 需求 | 状态 | 说明 |
| --- | --- | --- |
| 身份登录、刷新轮换、停用账号 | 已验证 | SQLite 集成测试覆盖停用登录和刷新令牌重用 |
| 课程草稿、发布和发布后修订 | 已验证 | 发布后更新标题不会替换已发布版本 |
| 学习心跳去重和 50% 进度 | 已验证 | 两门必修文档完成一门后进度为 50 |
| 考试幂等开始、答案冲突、重复交卷 | 已验证 | 未发布成绩对学生隐藏，其他学生读取答卷返回 404 |
| SM-2 复习提交 | 已验证 | 新卡片质量 4 得到间隔 1 天、重复次数 1 |
| 证书按资格去重 | 已验证 | 同一课程重复申请返回同一证书 |
| 查询注入片段拒绝，one 空结果 | 已验证 | 非法片段返回 400，未命中返回 data null |
| 组织范围 | 已验证 | 开启组织后，其他机构教师看不到课程 |
| 客观题精确评分、主观题待复核 | 已实现 | 领域单测覆盖客观题；主观题人工发布未做端到端浏览器验证 |
| 计划、通知、知识检索、学习报告 | 已实现 | 提供页面和接口；AI 关闭时建议使用固定文案 |
| AI 辅导 SSE | 已实现 | 事件顺序为 started、delta、completed；本环境未连接真实模型 |
| 单二进制嵌入前端 | 已实现 | `frontend` 构建到 `internal/web/dist` |
| MySQL / PostgreSQL 契约 | 未实现 | 驱动和 Compose profile 已提供，未在真实数据库上跑迁移和测试 |
| 性能、备份演练、AI 质量阈值 | 未实现 | 没有压测数据和模型评测集 |
| 就绪探针的数据库探测 | 未实现 | `/readyz` 只表示进程已装配 |
| 文件下载的选课授权 | 待确认 | 当前下载限于所有者和具备管理权限的用户 |
| SaaS 多租户 | 待确认 | 按单机构设计，组织只是可选范围 |
