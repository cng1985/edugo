# 设计取舍

- 进程是模块化单体。业务模块通过 Uber Fx 装配，仓储和 HTTP 处理器保持私有，跨模块只引用公开 `api`。
- 数据库默认 SQLite，并保留 MySQL、PostgreSQL 驱动。迁移使用一次版本化的 AutoMigrate，版本号记录在 `schema_migrations`。
- 领域事件写入 outbox。分发器在消费者处理完成后再写 inbox。这样避免 SQLite 单连接时，消费者再使用根连接造成死锁。消费者需要自行保持幂等；这与“inbox 和业务写入处于同一事务”的目标不完全相同。
- 分数在库内以百分之一分（centi）保存，接口以浮点分数返回。
- 复习算法固定为 `sm2-edugo-v1`。间隔按本地日历天计算，先用旧的难易度计算间隔，再更新难易度。
- 客观题自动评分要求答案集合精确匹配。主观题进入待复核，不写入 0 分作为正式成绩。未发布成绩对学生隐藏。
- AI 关闭时，登录、课程、学习和考试仍可运行。辅导、出题和路径生成返回能力未启用。学习建议在 AI 关闭时使用固定文案，并声明不会改写业务状态。
- 组织模块默认关闭。开启后，课程和考试按用户的 `orgId` 过滤。它不是 SaaS 租户隔离。
